# Dope Cute Studio - Site de vente de chapeaux

Site web statique de présentation d'une boutique de chapeaux.

## Fichiers

- `index.html` : page d'accueil.
- `styles.css` : styles de la page.
- `script.js` : logique front-end pour afficher les produits et simuler le panier.

## Utilisation

Ouvrez `index.html` dans votre navigateur ou servez le dossier avec un serveur local.

### Exemple avec Python

```powershell
python -m http.server 8000
```

Puis ouvrez `http://localhost:8000` dans votre navigateur.
