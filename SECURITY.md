# Security Policy

Do not disclose vulnerabilities in public issues.

Until a private security channel is configured, contact the repository owner
privately through GitHub. Never include credentials, personal data, payment
details, identity documents, access tokens, or production logs in an issue.

## Engineering rules

- No secrets in source control.
- No real financial or identity data in fixtures.
- Use environment-specific configuration.
- Review dependency changes.
- Treat authentication, payment and ledger code as security-critical.
