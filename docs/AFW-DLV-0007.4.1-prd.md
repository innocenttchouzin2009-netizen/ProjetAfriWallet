# AFW-DLV-0007.4.1 — Bank Registry & Routing

## Objective
Create a shared banking registry and deterministic routing foundation for future bank transfer integrations.

## Scope
- Central registry of banking providers
- Routing by country, currency, transfer scheme, and environment
- Seed data for sandbox development scenarios
- Minimal REST API for listing, searching, and routing

## Success Criteria
- Build succeeds
- Scenario runner passes
- Routing remains deterministic and environment-aware
- Documentation and API surface are available
