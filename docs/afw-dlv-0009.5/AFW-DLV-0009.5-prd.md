# AFW-DLV-0009.5 — Merchant Settlement Engine

## Summary
The settlement engine creates settlement instructions, applies fees and taxes, batches settlements, supports multiple settlement methods, and handles recovery from failed settlements without bypassing the payment gateway orchestration path.

## Scope
- Settlement instruction creation
- Fee and tax calculations
- Batch settlement scheduling
- Wallet, bank, and mobile money settlement execution
- Recovery for failed settlements
- Audit and telemetry generation
