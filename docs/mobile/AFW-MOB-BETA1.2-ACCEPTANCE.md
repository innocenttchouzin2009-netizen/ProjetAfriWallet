# AFW-MOB-BETA1.2 Acceptance Criteria

- Welcome experience transitions into onboarding.
- Onboarding presents identity, payments/QR and security concepts.
- User can choose Create account or Sign in.
- Create-account flow includes country selection.
- Access forms validate contact and PIN input locally.
- UI never treats local validation as successful backend authentication.
- No money movement, balance fabrication or ledger mutation is introduced.
- Flutter analyze and test gates must pass in CI.
- Delivery remains unfrozen until authoritative squash SHA and annotated tag parity are verified.
