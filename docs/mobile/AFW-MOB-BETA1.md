# AfWal Mobile Beta 1

Status: IN DEVELOPMENT

## Goal
Deliver the first coherent AfWal mobile experience suitable for progressive iOS/TestFlight preparation while preserving all frozen backend/platform history.

## Delivery line
1. AFW-MOB-BETA1.1 — Mobile Foundation & Design System
2. AFW-MOB-BETA1.2 — Onboarding & Authentication UX
3. AFW-MOB-BETA1.3 — AfWal ID & Security UX
4. AFW-MOB-BETA1.4 — Wallet Home & Multi-Currency Balances
5. AFW-MOB-BETA1.5 — Send, Receive & QR
6. AFW-MOB-BETA1.6 — Financial Timeline
7. AFW-MOB-BETA1.7 — Profile, Settings & Beta Hardening
8. AFW-MOB-BETA1.8 — iOS/TestFlight Release Candidate

## Beta 1 principles
- Deep green + gold AfWal identity.
- Mobile-first and highly intuitive navigation.
- Existing backend/platform boundaries remain authoritative.
- UI must never fabricate confirmed financial state.
- Sensitive actions require explicit authentication/security flows before production enablement.
- Beta functionality may use sandbox/demo states where backend integration is not production-ready, and such states must be clearly identified in engineering documentation.

## Current delivery
AFW-MOB-BETA1.1 establishes the visual foundation, premium Beta entry experience, and reusable theme tokens.
