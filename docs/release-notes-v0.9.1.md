# Release Notes v0.9.1

## Added
- Merchant registry domain model with merchant lifecycle and capability metadata.
- Merchant API endpoints for create, read, update, activate, suspend, and close.
- Merchant validation rules for supported countries, currencies, and required identity fields.
- QR payment and settlement scaffolding endpoints to support future merchant commerce flows.

## Validation
- Merchant API build verified with Release configuration.
- Merchant registry scenario suite passed for registration, validation, lifecycle changes, audit, and telemetry.

## Notes
This release focuses on the registry foundation and is intended to prepare the platform for AFW-DLV-0009.2 — Merchant Onboarding & KYC.
