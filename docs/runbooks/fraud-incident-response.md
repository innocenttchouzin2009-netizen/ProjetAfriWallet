# Fraud incident response

## Trigger
- spike in blocked payments
- unusual QR reuse
- repeated step-up failures

## Immediate actions
1. Review recent fraud assessments and review cases.
2. Check whether a rule version change caused the spike.
3. Temporarily disable the affected rule set if the impact is operationally unacceptable.
4. Escalate to the payment operations team if the issue persists.
