# Reason Codes

| Code | Meaning |
|---|---|
| `EvidenceSupportsClaim` | Investigation outcome supports the claim. |
| `EvidenceDoesNotSupportClaim` | Investigation outcome does not support the claim. |
| `InsufficientEvidence` | Investigation could not gather enough evidence. |
| `InvestigationRequiresEscalation` | Investigation outcome requires manual escalation. |
| `UnauthorizedTransaction` | Claim classified as an unauthorized transaction. |
| `DuplicateTransaction` | Claim classified as a duplicate charge. |
| `ProcessingError` | Claim classified as a processing error. |
| `GoodsOrServicesNotReceived` | Claim classified as goods/services not received. |
| `RefundNotProcessed` | Claim classified as a refund that was never processed. |
| `PolicyRequiresManualReview` | Investigation outcome is not recognized by policy. |
| `HighValueRequiresApproval` | Disputed amount meets or exceeds the manual approval threshold. |
| `UnsupportedClassification` | Claim classification is not covered by an automated rule. |
