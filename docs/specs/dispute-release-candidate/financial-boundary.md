# Dispute Release Candidate Financial Boundary

This release candidate packages the Sprint 18 Dispute Platform. It does not change or expand the financial boundary established by AFW-DLV-0018.1 through 0018.7.

The RC does not enable:

- real refund execution
- real chargeback submission
- real settlement
- automatic merchant blocking
- automatic customer suspension
- direct Universal Ledger mutation

Any future production financial execution requires a separately governed delivery outside Sprint 18.
