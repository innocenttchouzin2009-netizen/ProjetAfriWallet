# PRD - AFW-DLV-0013.2 Liquidity Management Engine

## Objective

Implement a liquidity engine that monitors, forecasts, and optimizes treasury liquidity without posting accounting entries.

## Scope

- Available, reserved, pending, and blocked liquidity states
- Net liquidity position by account and currency
- Threshold-based alerting
- Snapshot generation
- Liquidity forecast (J+1, J+7, J+30)
- Rebalancing recommendations
