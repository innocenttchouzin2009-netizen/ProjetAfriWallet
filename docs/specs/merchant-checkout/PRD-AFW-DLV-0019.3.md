# AFW-DLV-0019.3

## Checkout Session & Payment Intent Platform

Create the canonical merchant checkout session and payment intent lifecycle for verified, active merchants. It supports session creation, order correlation, metadata, expiry, cancellation, idempotency and tokenized payment-method references.

## Boundary

This delivery does not authorize, capture, settle, refund, pay out, move money, or write Universal Ledger entries. Raw PAN and CVV storage are not supported.
