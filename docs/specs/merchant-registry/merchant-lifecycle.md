# Merchant Lifecycle

## Draft

Merchant identity exists but registration is incomplete.

## Registered

Basic merchant profile has been registered.

## PendingVerification

Merchant is awaiting later verification orchestration. AFW-DLV-0019.1 does not perform KYB.

## Active

Administrative registry state. Does not mean payment acceptance is enabled.

## Suspended

Merchant registry usage is administratively suspended. AFW-DLV-0019.1 does not automatically block external payment rails.

## Closed

Terminal immutable state.
