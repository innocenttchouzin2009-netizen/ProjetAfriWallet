# Merchant Verification Policy - Sandbox v1

## Minimum document set

- BusinessRegistration
- ProofOfAddress
- OwnerIdentity

The minimum set moves a case from `PendingDocuments` to `ReadyForReview`.

## Review

A reviewer must be assigned before provider execution.

## Provider outcomes

- Verified
- Rejected
- ManualReviewRequired

## Policy status

These rules are internal sandbox rules. They are not represented as universal KYB or regulatory requirements.
