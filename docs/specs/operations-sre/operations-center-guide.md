# Operations Center Guide

The Operations Center is the production supervision surface for AfriWallet. It is read-first, workflow-driven, and backed by an aggregator service that summarizes service health, incidents, alerts, deployments, backups, and disaster recovery readiness.

## Operating model
- Use the dashboard for at-a-glance posture.
- Use incidents for live response and resolution.
- Use maintenance windows for planned interventions.
- Use backups and DR plans for resilience verification.
