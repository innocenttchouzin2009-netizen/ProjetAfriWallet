# PRD AFW-DLV-0014.8

## Overview

This release candidate consolidates the Payment Platform delivery scope that was validated in the preceding 0014.x deliveries and freezes the RC structure for release testing.

## Production boundary

AFW-DLV-0014.8 freezes the AfriWallet Payment Platform architecture
and validates the Release Candidate.

It does not certify external Mobile Money operators.

Orange Money, MTN MoMo, Airtel Money and M-Pesa remain sandbox
provider adapters until separate production onboarding,
credentials, contractual approval and provider certification
are completed.

## Scope

- Consolidate the validated payment release package.
- Validate the release candidate gate.
- Produce the described manifest, checksum, and report artifacts.
- Prepare the Sprint 14 closeout and freeze.

## Non-goals

This release does not add new business functionality. It is a packaging and validation release only.
