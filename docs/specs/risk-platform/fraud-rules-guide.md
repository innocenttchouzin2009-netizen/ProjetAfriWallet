# Fraud Rules Guide

- Amount threshold: block high-value transactions above configured limits.
- Velocity window: review bursts of fast repeated payments.
- Unknown device: review or block when device reputation is unknown.
- Geo anomaly: review country or location changes.
- New beneficiary: review newly added beneficiaries.
- Repeated failures: block repeated failures after several attempts.
- Merchant threshold: review high-risk merchant profiles.
