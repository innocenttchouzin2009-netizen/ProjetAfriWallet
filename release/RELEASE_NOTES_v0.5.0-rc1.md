# AfriWallet Release Candidate v0.5.0-rc1

## Summary
AfriWallet v0.5.0-rc1 is the feature-freeze release candidate for the Sprint 5 stabilization and preproduction readiness milestone.

## Included capabilities
- Identity service with session and trust-device readiness
- Wallet, ledger, balance projection, and FX foundations
- Payment flow orchestration and notification readiness
- Fraud controls and resilience hardening
- Security, performance, disaster recovery, and CI/CD scaffolding
- Flutter mobile experience with wallet, AfriCard, and subscriptions views

## Release readiness
- Build entry point verified
- Scenario-based backend validation executed
- OpenAPI, ADR, and runbook documentation included
- Release artifacts and package structure prepared for tagging
