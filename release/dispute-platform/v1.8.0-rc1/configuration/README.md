# Configuration

The Dispute Platform v1.8.0-rc1 ships with sandbox-only infrastructure bindings:

- `SandboxDisputeEligibilityReader`, `SandboxInvestigationOutcomeReader`, `SandboxDisputeDecisionReader`, `SandboxResolutionProvider`, `SandboxDisputeIntelligenceSource`

No production processor, bank, card-scheme, or settlement configuration is included in this release candidate.
