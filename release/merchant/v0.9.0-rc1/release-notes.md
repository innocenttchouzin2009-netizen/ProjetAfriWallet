# Merchant Release Candidate v0.9.0-rc1

## Overview
This release candidate freezes the Sprint 9 merchant platform capabilities and prepares the ecosystem for integration testing and partner onboarding.

## Included capabilities
- Merchant registry and lifecycle management
- Merchant onboarding and KYC workflow
- QR payment generation, initiation, and receipt handling
- Merchant API, POS checkout, and terminal flows
- Settlement instruction and execution workflow
- Merchant dashboard experience and analytics shell
- Production-readiness controls and release packaging
